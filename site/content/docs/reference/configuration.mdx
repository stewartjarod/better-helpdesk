title: Configuration

`HelpdeskConfig` is the one object that `buildHelpdesk(config)` from `better-helpdesk` takes. The fields below are grouped by what they serve; the order inside the type is different. Inboxes have [a page of their own](/docs/inbox/inboxes), and the adapter interfaces are on [Adapters](/docs/reference/adapters).

```ts title="lib/helpdesk.ts"
import { buildHelpdesk, postgresAdapter } from 'better-helpdesk';
import { pool } from './db'; // a pg.Pool

export const helpdesk = buildHelpdesk({
  db: postgresAdapter({ pool }),
  referencePrefix: 'ACME',
  adminUrl: 'https://app.example.com/helpdesk/',
  inboxes: { support: {} },
  identify: async () => null,
});
```

## Required

<TypeTable
  type={{
    db: {
      type: 'DatabaseAdapter',
      required: true,
      description: <>Where the helpdesk keeps its data. <code>postgresAdapter({'{ pool }'})</code> builds it over a <code>pg.Pool</code>; <code>mysqlAdapter</code>, <code>mssqlAdapter</code> and <code>sqliteAdapter</code> over the other databases, as <a href="/docs/database/connect">Choose and connect a database</a> shows, and <code>createAdapter</code> over <a href="/docs/database/own-adapter">an adapter of your own</a>.</>,
    },
    referencePrefix: {
      type: 'string',
      required: true,
      description: <>Prefix of the human-readable reference, <code>PREFIX-number</code>. <code>ACME</code> gives <code>ACME-1042</code>. Numbers come from the <a href="/docs/database/tables#counter"><code>counter</code></a> table and start at 1000.</>,
    },
    adminUrl: {
      type: 'string',
      required: true,
      description: <>Absolute URL of the agent UI. Agent emails link to <code>{'{adminUrl}'}/conversations/{'{id}'}/</code>. Its origin is the only one, besides an inbox's <code>allowedOrigins</code> on widget routes, that mutations are accepted from. Rating links are built against it.</>,
    },
    inboxes: {
      type: 'Record<string, InboxConfig>',
      required: true,
      description: <>The inboxes by key. See <a href="/docs/inbox/inboxes">Inboxes</a>.</>,
    },
    identify: {
      type: '(request: Request) => Promise<Identity | null>',
      required: true,
      description: <>Turns a request into the host's signed-in user, or <code>null</code> for an anonymous visitor. Called by every route that needs the caller, which is every <code>widget/*</code> route but <code>widget/help</code>, and every <code>agent/*</code> route. On agent routes it is the only source of identity, and <code>isAgent: true</code> is required. See <a href="#identity">Identity</a>.</>,
    },
  }}
/>

## Routing and identity

<TypeTable
  type={{
    basePath: {
      type: 'string',
      default: "'/api/helpdesk'",
      description: 'Mount path of the route handler. A trailing slash is removed.',
    },
    identityTokenSecret: {
      type: 'string',
      description: <>Secret for the HS256 JWTs a host on another origin passes in <code>x-helpdesk-identity</code>. Consulted only when <code>identify</code> returns <code>null</code>. Shorter than 32 bytes, <code>buildHelpdesk</code> throws. A token never grants the agent UI.</>,
    },
    clientIp: {
      type: '(request: Request) => string | null',
      description: <>The caller's address as the host's proxy reports it, for rate limits. Unset, the last <code>X-Forwarded-For</code> hop is used, then <code>X-Real-IP</code>. <code>null</code> or no address counts as <code>unknown</code>. IPv6 addresses count per <code>/64</code>.</>,
    },
  }}
/>

## Startup checks

`buildHelpdesk` throws when:

- `identityTokenSecret` is set and shorter than 32 bytes.
- An inbox's `hours` fails validation; the message names the inbox. The rules are on [Inboxes](/docs/inbox/inboxes#businesshours).

## Translated

Copy you write per language: `{ en: string } & Partial<Record<Locale, string>>`. English is required, and a language you leave out shows the English text, so adding a language to the package never breaks your build. The qualifying question's labels and [CustomFieldDef](#customfielddef) use it.
